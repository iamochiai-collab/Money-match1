## かわったところ
- デザインを作り直しました。PC・タブレット・スマホ（たて・よこ）のどれでも、画面にあわせて並びかたが変わります。
- 青いトレーにお金を運ぶ形にしました。値札・トレー・さいふの3つだけのシンプルな画面です。
- 硬貨の大きさを、本物の大きさの比率にあわせました（1円が小さく、500円が大きい）。
- 硬貨の画像の透けていたところを直しました。
- 正解するとはなまるが出ます。ちがうときは「まだ すこし たりないよ」「おおすぎるよ」と出ます。
- 「？」ボタンに、あそびかたと先生用の設定があります。
  - タップでも うごかす（オフにすると、ドラッグだけで動きます）
  - ごうけいを みせる
  - おと
- レベル6で、作れない問題がまじっていたのを直しました（10円玉がない問題は5円玉を8まいに、50円玉がない問題は10円玉を9まいにしました）。
- タイトルの右の小さい番号（v25 など）で新しい版かどうかわかります。
